## 🤖 About

**Mythos Cyber AI** is a specialized cybersecurity tool and assistant designed for security awareness, threat analysis, and automated defensive tasks.

---

## ✨ Features

- 🔐 Cybersecurity awareness tools
- 🛡️ Threat analysis & detection
- 🤖 AI-powered defensive assistance
- 📊 Security reporting
- 🌐 Network security insights

```bash

# Go into the folder
cd mythospramod

# Open in browser
open index.html
```
